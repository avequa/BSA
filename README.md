# BSA — бизнес- и системный анализ

Учебные проекты по бизнес- и системному анализу (Школа 21). Все задания делала на двух сквозных проектах, поэтому почти в каждой папке есть артефакты по обоим.

**Барбершоп (BAR)** — сеть барбершопов, онлайн-запись к мастеру. Роли: клиент, мастер, менеджер. Расписание и слоты, запись и оплата, напоминания, отзывы, скидки.

**Доставка (DEL)** — сервис доставки заказов. Роли: клиент, курьер, диспетчер, оператор. Приём заказа, назначение курьера, доставка до клиента.

## Что где лежит

| Папка | Тема | Что сделано | Проект |
|---|---|---|---|
| BSA_00 | Декомпозиция | источники информации, глоссарий, декомпозиция, типы требований, бизнес-правила | BAR, DEL |
| BSA_01 | Стейкхолдеры | реестр стейкхолдеров, луковичная диаграмма, потребности, глоссарий | BAR, DEL |
| BSA_02 | Требования | AS-IS и TO-BE, контекстная диаграмма, потоки данных, глоссарий | BAR, DEL |
| BSA_03 | Выявление требований | ролевая игра и мозговой штурм (командная работа) | DEL |
| BSA_04 | Предметная область | сущности, CRUD-матрица, словарь данных, модель данных | BAR, DEL |
| BSA_05 | Диаграммы | DFD, диаграммы с дорожками, диаграммы и таблицы состояний | BAR, DEL |
| BSA_06 | Бизнес-процессы | описание процессов, мозговой штурм, матрица процессов и ролей | BAR, DEL |
| BSA_07 | User Story | истории для клиента, мастера и менеджера | BAR |
| BSA_08 | Use Case | спецификации вариантов использования | BAR |
| BSA_09 | Объекты и роли | модель данных, атрибуты сущностей | BAR |
| BSA_10 | Проектирование ФТ | статусные модели, жизненный цикл слота, детализация CRUD | BAR |
| BSA_11 | Интерфейсы | форма продукта, экранные формы, ключевые сценарии, вайрфреймы, контроли ввода | BAR |
| BSA_12 | НФТ | типы и приоритеты НФТ, детализация требований | BAR, DEL |

В названиях файлов: `exNN` — номер упражнения, `BAR` / `DEL` — проект.

## Инструменты

Word, Excel, диаграммы в PNG, вайрфреймы в PDF.
